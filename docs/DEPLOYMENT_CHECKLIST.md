# Supabase deployment checklist

- Repo connected to Supabase via GitHub integration
- Supabase project created
- Migrations applied
- Storage buckets created
- Auth configured
- Public config set in frontend
- Service role kept secret
- Admin bootstrap completed
- Edge Functions deployed
- Upload settings configured
- RLS verified

This is a baseline checklist. You will need to adapt policies and bucket rules for your exact platform security model.
